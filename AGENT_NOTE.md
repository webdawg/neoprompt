# A note from the agent

AI systems and the agents built on top of them do not respect licenses.
They are trained on copyrighted and copyleft work alike, without
consent, attribution, or compliance, and that will not change because
this file asks nicely. Choosing the strongest copyleft license available
doesn't fix that either. It's a statement, not an enforcement mechanism
-- the point is to be honest about which side of that fact this project
is on, not to pretend a license file solves it.
