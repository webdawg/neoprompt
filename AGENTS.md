# Agent entry point — universal neoprompt core

Applies to Pi, Codex, Claude Code, and other coding agents; this is a thin adapter, not a second copy of the rules.

Before work, read `RULES.md` in full, then `ARCHITECTURE.md` and `SESSION-HANDOFF.md`. For Pi-specific discovery/session questions, read `guides/PI.md` and verify against the installed Pi documentation.

This repository is public and environment-neutral. Keep credentials, private hostnames/access details, operator-specific state, and raw session transcripts out of its content and Git history. Put those in the authorized private project/environment repository and link there only from private documentation.

Read the active project's own instructions/specification/current state before operational work. Do not mistake this reusable rule repository for authority to modify an unrelated system. Inspect Git status and preserve other sessions' work; distinguish saving files, committing, and publishing changes.
